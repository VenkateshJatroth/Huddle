## Scope boundary

The profile SQL has `avatar_url` but no upload feature. Region, language, interest and demo post data are labeled sample content and are not profile columns. The database drafts are documentation artifacts, and types in `src/lib/database.types.ts` mirror those drafts rather than prove them present.
